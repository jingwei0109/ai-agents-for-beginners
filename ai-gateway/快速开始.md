# 🚀 AI Gateway 快速开始指南

## 📦 安装

### 1. 克隆项目

```bash
cd /workspace/ai-gateway
```

### 2. 安装依赖

```bash
pip install -r requirements.txt
```

### 3. 配置环境变量

```bash
# 复制配置模板
cp .env.example .env

# 编辑 .env 文件
nano .env  # 或使用你喜欢的编辑器
```

在 `.env` 文件中至少配置一个提供商：

```bash
# 推荐：使用 GitHub Models (免费)
GITHUB_TOKEN=ghp_your_token_here

# 或使用 OpenAI
# OPENAI_API_KEY=sk-your_key_here

# 或使用 Azure OpenAI
# AZURE_OPENAI_API_KEY=your_key
# AZURE_OPENAI_ENDPOINT=https://your-resource.openai.azure.com/
```

## 💻 代码示例

### 最简单的使用

```python
import asyncio
from ai_gateway import AIGateway, GitHubModelsProvider, Message, MessageRole

async def main():
    # 创建网关
    gateway = AIGateway()
    
    # 添加提供商
    gateway.add_provider(
        "github",
        GitHubModelsProvider(api_key="your_token")
    )
    
    # 发送请求
    response = await gateway.complete(
        messages=[
            Message(role=MessageRole.USER, content="Hello!")
        ],
        model="gpt-4o-mini"
    )
    
    print(response.content)

asyncio.run(main())
```

### 使用缓存

```python
# 第一次请求 - 从API获取
response1 = await gateway.complete(
    messages=[Message(role=MessageRole.USER, content="What is AI?")],
    model="gpt-4o-mini"
)
print(f"Cached: {response1.cached}")  # False
print(f"Latency: {response1.latency_ms}ms")  # ~2000ms

# 第二次相同请求 - 从缓存获取
response2 = await gateway.complete(
    messages=[Message(role=MessageRole.USER, content="What is AI?")],
    model="gpt-4o-mini"
)
print(f"Cached: {response2.cached}")  # True
print(f"Latency: {response2.latency_ms}ms")  # ~5ms
```

### 流式输出

```python
async for chunk in gateway.complete_stream(
    messages=[Message(role=MessageRole.USER, content="Write a story")],
    model="gpt-4o-mini"
):
    print(chunk, end="", flush=True)
```

### 多提供商 + Fallback

```python
# 添加主提供商（优先级1）
gateway.add_provider(
    "github",
    GitHubModelsProvider(api_key="..."),
    priority=1
)

# 添加备用提供商（优先级2）
gateway.add_provider(
    "openai",
    OpenAIProvider(api_key="..."),
    priority=2
)

# 请求会优先使用 GitHub，如果失败会自动切换到 OpenAI
response = await gateway.complete(...)
```

## ❓ 常见问题

### Q: 提示"No enabled providers available"
A: 确保已配置至少一个有效的API密钥，并添加到网关中

### Q: 缓存不工作
A: 确保 `enable_cache=True` 且请求参数（messages, model, temperature）完全相同

### Q: 如何禁用缓存
A: 在请求时设置 `use_cache=False` 或创建网关时设置 `enable_cache=False`

### Q: 支持哪些模型
A: 取决于你使用的提供商，可通过 `provider.get_available_models()` 查询
