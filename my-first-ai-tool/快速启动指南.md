# 🚀 5分钟快速启动指南

## 第一步: 安装依赖 (2分钟)

```bash
# 打开终端,进入项目目录
cd /workspace/my-first-ai-tool

# 安装所有依赖
pip install -r requirements.txt
```

## 第二步: 配置环境变量 (1分钟)

### 方案 A: 使用 GitHub Models (推荐,免费)

1. 访问 https://github.com/settings/tokens
2. 点击 "Generate new token" → "Generate new token (classic)"
3. 给 token 命名,如 "AI Agent Tool"
4. 勾选 `repo` 和 `read:user` 权限
5. 点击 "Generate token" 并复制 token

6. 创建 `.env` 文件:
```bash
# 在项目根目录创建 .env 文件
cp .env.example .env

# 编辑 .env 文件,粘贴你的 token
# 使用 nano 或 vim 或 Cursor 编辑器
nano .env
```

7. 在 `.env` 中填入:
```bash
GITHUB_TOKEN=ghp_你的token
```

### 方案 B: 使用 Azure OpenAI

在 `.env` 中填入:
```bash
AZURE_OPENAI_ENDPOINT=https://your-endpoint.openai.azure.com/
AZURE_OPENAI_API_KEY=your_key
AZURE_OPENAI_DEPLOYMENT_NAME=gpt-4o-mini
AZURE_OPENAI_API_VERSION=2024-05-01-preview
```

然后修改 `agents/travel_agent.py`:
```python
# 替换这部分代码:
from semantic_kernel.connectors.ai.open_ai import AzureOpenAIChatCompletion

chat_service = AzureOpenAIChatCompletion(
    deployment_name=os.getenv("AZURE_OPENAI_DEPLOYMENT_NAME"),
    endpoint=os.getenv("AZURE_OPENAI_ENDPOINT"),
    api_key=os.getenv("AZURE_OPENAI_API_KEY")
)
```

## 第三步: 运行应用 (1分钟)

```bash
# 启动 Chainlit 应用
chainlit run app.py -w
```

浏览器会自动打开 `http://localhost:8000`

## 🔧 故障排除

### 问题 1: 依赖安装失败
```bash
# 升级 pip
pip install --upgrade pip

# 重新安装
pip install -r requirements.txt
```

### 问题 2: Agent 没有响应
- 检查 `.env` 文件是否存在
- 确认 GITHUB_TOKEN 正确无误
- 检查网络连接

### 问题 3: Chainlit 启动失败
```bash
# 检查端口是否被占用
lsof -i :8000

# 更换端口运行
chainlit run app.py --port 8080
```
